💡 What This Project Actually Is

portable-heart-led is an open hardware project. That means the design files, the code, and the build instructions are all published so anyone can download them, look at them, change them, and build their own version.

The heart itself is a piece of electronics about the size of a coin. Sixteen small LEDs sit behind a heart-shaped front panel. A tiny Arduino Nano board controls how they light up, so the heart can pulse, fade, blink, or hold a steady glow. Power comes from a small rechargeable lithium battery, and a built-in charging chip means you never have to open the case to charge it. Just plug in a USB cable and it tops itself up.

The download package contains the complete wiring schematic, the Arduino sketch (the code that makes the LEDs animate), the circuit board design files, and a written build guide. You do not need to write a single line of code. It is already done.

🔧 What You Will Need

These are physical parts, not software. The parts list in the download names each one precisely, but here is the short version so you know what you are getting into:

  • An Arduino Nano board (the small controller).
  • Sixteen LEDs in the color of your choice.
  • A small rechargeable lithium battery.
  • A charging module for that battery.
  • A voltage booster module, so the battery can drive all the LEDs evenly.
  • Resistors, a switch, and a keyring loop.
  • A soldering iron, solder, and a pair of wire cutters.

None of these are expensive, and most are sold in small beginner packs. If you have never soldered before, buy a cheap practice board first and spend twenty minutes learning on it. That single step prevents almost every problem people run into.

🧩 How the Build Goes

Step one: lay out the parts

Empty the parts onto a clean, well-lit table. Match each item against the parts list and tick it off. Missing a resistor is the most common reason a build stalls halfway.

Step two: follow the schematic

The schematic shows the connections as lines. Follow one line at a time, from start to finish, and do not jump around. Slow and boring beats fast and confusing every time.

Step three: upload the code

Connect the Arduino Nano to your computer with a USB cable, open the code file from the download in the free Arduino editor, and press the upload button. The guide walks you through this with pictures.

Step four: test before you close it up

Power the heart on while it is still open on the table. If every LED lights up, you are done. If not, the troubleshooting section below covers the usual suspects.

Step five: assemble the case

Fit everything into the heart-shaped shell, attach the keyring loop, and charge it fully before first use.

🔋 Using Your Heart Keychain

Once it is built, using it is simple. Slide the small switch to turn it on and the heart begins its animation. Slide it back to turn it off and save battery. When the lights start to look dim, plug a USB cable into the charging port and leave it for an hour or two. A full charge lasts through days of normal on-and-off use.

Treat it like any small electronic device: keep it dry, avoid dropping it on hard floors, and do not leave it charging unattended for very long periods.

🛠️ Troubleshooting

  • No LEDs light up at all. Check the battery is charged and the switch is actually in the on position. Then check the battery connections — a loose wire is the usual culprit.
  • Some LEDs light, others do not. An LED has a direction. One installed backwards will stay dark. Desolder it and flip it around.
  • Lights are dim or flicker. The battery is probably low. Charge it fully and test again.
  • Nothing happens when you upload code. Make sure the correct board type is selected in the editor and that the USB cable carries data, not just power. Some cables only charge.
  • The animation runs too fast or too slow. Open the code and look for the delay numbers near the top. Larger numbers mean slower animation.

❓ Common Questions

Do I need to know how to code?

No. The code is finished and ready to upload. You only touch it if you want to change how the heart behaves.

Can I build it without a custom circuit board?

Yes. The guide explains how to build the same circuit on ordinary prototyping board, which is cheaper for a one-off build.

Is it safe for a beginner?

Yes, with normal care. The voltages are low. The only real hazards are a hot soldering iron and the lithium battery, so read the safety notes in the build guide before starting.

Can I sell the things I build?

Check the license file in the download. Open hardware projects usually allow personal builds freely and have separate rules for selling.
